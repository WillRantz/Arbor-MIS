Good to know

Frequently asked questions

Important information before you try the demo.

What is the Arbor MIS beta?

It is a demonstration of a school management interface and its available features. It should not be treated as an official Arbor product or an operational school management system.

How do I open it?

Keep this index.html file in the same folder as arbor-mis-parent-tabs-fixed.html. Open this page and select any of the Open beta or Launch the beta links.

Does the demo need installing?

The demo is designed to run in a browser from an HTML file. If you host the website online, upload both HTML files and preserve their filenames.

Will my information be shared across devices?

The current demo may store information in browser local storage. That does not create a secure shared database, and data may not appear on another browser or device.

Can I use real student information?

No. Use fictional test data only. This demo is not a substitute for a secure, compliant school information system.

Is this an official Arbor website?

No. This is a beta demo landing page. It is not affiliated with or endorsed by the official Arbor brand.
